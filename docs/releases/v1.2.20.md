## 本次更新

### 独立 IDE
- 资源管理器补上多选与文件操作：Ctrl / Shift 多选、全选、拖拽移动（按住 Ctrl / Alt 拖动为复制）、内部复制 / 剪切 / 粘贴、多选删除
- 资源管理器可以切换隐藏文件，以及 `node_modules`、`dist` 等忽略目录；每个工作区还能自定义忽略 glob（匹配文件名或相对路径）
- 新增右侧审阅栏：按文件汇总工作区改动，展开与 HEAD 比较的 hunk 摘要，点击打开对应 diff；没有改动或不是仓库时自动收起
- 编辑器顶部新增路径 + 符号面包屑，点击可跳到文件或定义
- `Ctrl+N` 新建未命名缓冲区，支持另存为、手动切换语言模式、切换 LF / CRLF；未保存前一直标记为未保存
- 打开文件时自动识别编码：BOM、UTF-8、GBK / GB18030、Big5、Shift-JIS、EUC-JP / KR、UTF-16 / 32，以及常见的西欧 / 俄文单字节编码；状态栏可手动改写或恢复自动检测
- 读取工作区 `.editorconfig`：`indent_style` / `indent_size` / `tab_width` / `end_of_line` / `insert_final_newline` / `trim_trailing_whitespace`，优先级高于全局设置和按语言配置
- 编辑器偏好扩展到：字体、连字、行高、字距、换行列宽、光标形状 / 闪烁 / 平滑移动、当前行高亮、空白与控制字符、行号（含相对行号）、缩进 / 括号对参考线、列标尺、代码缩略图、粘性滚动、平滑滚动、Ctrl + 滚轮缩放、保存时格式化、按语言覆盖缩进；终端字号和行高单独可调
- 搜索替换结果按文件折叠，替换前提供逐文件预览，替换后可撤销一次；搜索历史按工作区保存；替换后又被外部修改的文件会跳过
- LSP 的文档符号同时用于面包屑和当前文件符号搜索

### 界面与主题
- 星野主题改为极光帷幕：左薄荷 / 右紫 / 中青三层底光、SVG 幕帘、细竖纹与地平线光，星点更密并加入疏散星团
- 新会话空态重做：四张上手卡片说明 `@`、`/`、图片与执行者，配快捷键提示，垂直居中并随主题明暗适配
- 思考深度滑轨加入粒子、电弧与涟漪反馈，按档位调整颜色和强度，尊重系统「减少动态效果」设置
