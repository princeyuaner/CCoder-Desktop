## 本次更新

### 性能与稳定性
- dsh / codex 会话列表改为增量扫描：递归监听会话目录，没变的记录直接复用上次的解析结果，连 `stat` 都不做；60 秒全量校验兜底
- dsh 的投影缓存（标题 / cwd / blank）单独监听，标题变更不用等到下一次全量校验
- 轮末一次报出的几十到几百个文件改动合并成一次界面更新，不再每个路径触发一次重渲染
- 切走的会话最多保留 8 条缓存；超出后按最久未打开回收，且只回收没在跑、没排队、没有后台任务和待审批的会话
- 追加写的会话记录变长时直接复用已解析的 cwd / 标题 / 创建时间，不再每轮重读 32KB 文件头
- codex 的目录遍历改为按目录并发

### 实测
- 本机 35 条 dsh 会话：单趟扫描 31ms → 3~5ms
- 完整会话列表 warm 刷新：31~36ms → 6~9.5ms
- 大会话：115MB 记录回放约 6.4k 事件，主线程侧 replay 约 23ms
