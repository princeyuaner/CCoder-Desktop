## 本次更新

### 新增

- **自动化任务**：侧栏新增一级入口，按**每隔 N 分钟 / 每天 / 每周**的计划在后台拉起一条普通会话。任务级配置覆盖工作区、CLI、模型、思考深度、权限模式、提示词、单轮超时、单次预算和通知开关；每次运行都留成可回看、可续跑的会话。无人值守时权限请求自动拒绝，`AskUserQuestion` 可以选「暂停并通知」或「跳过并继续」，超时会直接收掉进程。运行记录、耗时、花费和结果持久化在本机，成功 / 失败弹系统通知，点击回到对应会话。
- **语音输入**：输入框底栏新增麦克风，也可以按 `Ctrl+Shift+M` 开始 / 结束录音；转写文字插入光标处（有选区时替换选区），并可一键撤销。默认走硅基流动的免费额度，也可切换 Groq 或自填任意 OpenAI 兼容端点；识别语言、插入方式、自动发送和快捷键都在「设置 → 系统 → 语音输入」里配置。

### 改进

- **执行台改版**：计时器作为头部锚点，任务、子代理、后台任务各自分区滚动。子代理卡片按类型配图标，并用左侧色条 + 右上角状态胶囊双重标记状态，活动行只保留「工具 + 正在做什么」；后台 shell / workflow 单独成区，不再混进子代理；子代理完成后可以直接打开完整报告。
- **执行台在矮窗口下的高度分配**：后台任务很多时，不再按内容高度抢走可用空间、把子代理区压成半张卡。子代理区至少保留一张完整卡片的高度；窗口极矮时整个面板兜底滚动，不会直接裁掉最后一块。
- **macOS 麦克风权限**：macOS 包补充了麦克风用途说明和音频输入 entitlement，首次录音时系统会正常弹出授权，不再直接被拒绝。

### 注意

- 自动化调度只在应用运行时生效；关掉最后一个窗口后停止，下次启动会补跑一次错过的计划。
- 无人值守运行会真实消耗额度，预算在每轮结束时结算；权限请求会被自动拒绝，需要你回答的问题按任务策略处理。
- 语音录音只保存在内存，停止后直接发送到所选服务商，应用不写入音频文件；macOS 首次使用需要在系统提示中允许麦克风。
- 硅基流动的免费额度和可用模型由服务商调整，接入时以控制台为准；服务地址保持可编辑，换服务商不用改代码。
