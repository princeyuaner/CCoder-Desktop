## 本次更新

### 新增

- **工具卡悬停预览**：鼠标停在工具行上约 90ms 后浮出预览卡，按工具类型展示命令、输出前几行、完整路径、`+N −M` 增删行、错误摘要和运行状态。浮层只做预览、不接管鼠标，扫过整列工具行不会被挡住；滚出视野自动收起，完整内容仍然点开卡片查看。
- **浮层跟随主题**：深浅色、星野和六套氛围主题都有对应配色；半透明主题下浮层垫了不透明底，避免下层文字透上来影响阅读。

### 改进

- **等待与思考的星核动效**：等待响应和思考行的标记换成星核 —— 核心呼吸、卫星沿椭圆轨道、标题渐变流光；展开的思考卡带扫描光带。浅色与星野主题有单独配色，系统开启「减少动态效果」时自动停下。
- **拖入文件自动识别编码**（本次一并包含 1.2.25 的改动）：拖进 / 选进输入框的文本文件不再一律按 UTF-8 读取，按 BOM、UTF-16 / 32、严格 UTF-8 依次识别，识别不出时回落到 GB18030；非 UTF-8 的源编码会标在引用卡上。无 BOM 的宽字符文件不再被当成二进制，512 KB 截断也不会留下半个替换符。

### 注意

- 悬停浮层是纯预览：复制、展开和在 IDE 中打开仍走原来的卡片交互；运行中的工具在预览里也能看到已经返回的部分输出。
- 纯 CJK、无 BOM 且完全不含 ASCII 的 UTF-16 文件在统计上无法与 GB18030 等旧编码稳定区分，仍可能按 GB18030 读成乱码。
- 星核动效在 `prefers-reduced-motion: reduce` 下自动停用，不影响等待计时和状态文案。
