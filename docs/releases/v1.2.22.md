## 本次更新

### 新增
- 六套带氛围背景的主题：
  - **极光**：青绿与紫罗兰极光带在窗口底层缓慢流动。
  - **余烬**：暖橙炉光配上升火星，适合深夜长时间写代码。
  - **深渊**：深海光束与荧光浮游生物，冷静、低干扰。
  - **樱夜**：靛紫夜色中的落樱与霓虹粉光晕。
  - **全息棱镜**：石墨底上缓慢流动的虹彩，克制的赛博质感。
  - **冰川晨曦**：冰蓝浅色、磨砂玻璃面板与顶部极光，白天也有氛围。
- 氛围主题下，标题栏、侧栏、输入框、代码块和工具卡改为半透明玻璃，让背景透出来；正文区域保留暗角 / 亮角垫层，保证可读性。
- 极光、余烬、深渊、樱夜、全息棱镜、冰川晨曦已加入设置页的深色 / 浅色主题分组，中英文标签同步补齐。
- 开启「减少动态」（`prefers-reduced-motion`）时，光晕动画和 canvas 粒子层全部停止，只保留静态柔光。

### 改进
- 背景层挂载逻辑从星野主题抽成通用实现：切换到普通主题时会正确卸载背景，不会残留在窗口底层。
- 设置页主题提示文案更新，说明部分主题会附带动态背景。
- IDE 编辑器细节改进：草稿按文件保存并在重启后恢复，旧版按工作区存储的草稿会自动迁移；状态栏显示光标行列，面包屑跟随光标更新；打开文件时的加载占位更稳定，切换页签不会丢失编辑器状态。

## 安装
Windows 安装版支持自动更新；便携版需手动下载。从 1.2.21 及更早版本手动安装一次 1.2.22 后，后续更新即可正常在应用内下载。
