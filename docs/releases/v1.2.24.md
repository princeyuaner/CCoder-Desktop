## 本次更新

### 新增

- **插件系统**：侧栏新增一级「插件」页，支持两种插件：
  - **免代码**：`manifest.json` + 可选 `styles.css`，不运行 JavaScript，适合主题、静态状态栏和纯样式调整。
  - **需要运行代码**：`manifest.json` + 单文件 ESM `main.js`，通过 `activate(ctx)` 注册状态栏、命令、设置页、主区页签，使用插件自己的存储和事件总线。
  - 本地目录安装、热重载、启用 / 禁用 / 卸载；插件数据隔离在 `userData/plugin-data`。
  - 权限按低 / 中 / 高风险分级，安装前展开可看「能访问什么 / 不会访问什么」。
  - 插件市场读取静态索引，下载 zip 后校验大小与 sha256 再安装；远程索引不可用时回退到包内置索引。开发模式优先使用仓库里的 `docs/plugins/index.json`。
- **输入框跑马灯**示例插件已上架市场：会话运行中在输入框边框显示追光，轮次结束自动淡出；纯 CSS，`permissions: []`。也作为 `docs/plugins/examples/ccoder-composer-marquee` 提供本地安装。
- **文件检查点**：每轮开始前自动给工作区拍快照。会话菜单 →「文件检查点」可以预览恢复会改动哪些文件，并回到任意一轮开始前的状态；恢复前自动再拍一份备份，恢复错了还能恢复回来。快照使用应用自己的 shadow git 仓库，不碰用户仓库的 HEAD / index / stash。
- **会话分叉**：会话菜单 →「分叉会话」把当前对话复制成一条新会话。Claude 使用 `--fork-session`，Codex 使用 app-server 的 `thread/fork`；分叉拥有自己的会话记录，后续修改不会回写原会话。dsh（ACP 0.2.1）没有 fork 能力，入口禁用。

### 改进

- **便携版数据隔离**：便携版把配置写到 exe 同级的 `CCoderData`，不再和安装版共用 `%APPDATA%`，同时启动时不会再因为 Chromium profile 锁互相挤掉。
- **插件市场内置兜底**：打包时把市场索引和示例产物复制到 `resources/plugin-market/`，断网或远端索引不可用时市场页仍然可用。
- 插件样式注入会拒绝 `@import`、远程 `url(...)` 和 `expression(...)`；插件面板会显示实际安装目录，便于排查。

### 注意

- 插件 v1 只适合安装**可信来源**的插件。免代码插件只注入 CSS；需要运行代码的插件与宿主同处一个 renderer 世界，能够访问 `window.api`，权限检查是能力门禁而不是安全沙箱。发布者签名和沙箱隔离会在后续版本补齐。
- 文件检查点只覆盖会话工作目录，`--add-dir` 附加目录不参与；`.gitignore` 和应用忽略表里的文件不会进入快照。恢复只还原文件，不回退会话记录；需要对话也回到那一轮请用分叉。
- 首次快照需要扫描工作区，超大仓库的第一轮可能较慢；超时后该工作区在本次运行内不再拍检查点，重启应用可重试。

## 安装

Windows 安装版从 1.2.23 起可直接在应用内更新；1.2.22 及更早版本需要手动安装一次 1.2.24，后续更新即可正常在应用内下载。便携版需手动下载。构建未做代码签名，Windows 可能提示未知发布者。
