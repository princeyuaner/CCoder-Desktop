## 本次更新

### 性能与稳定性
- 会话列表改为增量扫描：监听 `~/.claude/projects` 的写入，只重扫变动过的 `.jsonl`；其余记录直接复用上次解析结果，连 `stat` 都跳过，Windows 上几百份文件的每趟 IO 尖刺随之消失
- 监听不可用时自动退回全量扫描，并每 60 秒兜底校验一次，避免漏掉丢失或合并的文件事件
- 缓存里的 `createdAt` 改存解析后的值，增量快路径不会把 0 带到下一次扫描
- 打开旧会话时，卡片、轮数、步数、用量、输入历史和「本轮修改」合并成一次遍历，不再各扫一遍
- 历史回放期间原地构建列表，不再每来一条事件整表浅拷贝，大会话首屏开销从 O(n²) 降到 O(n)
- 「本轮修改」的归约规则抽成 `reduceFiles`，实时流与历史回放共用同一口径
