## 本次更新

### 新增
- **整文件 diff 视图**：差异页签按整文件渲染，未修改的行也会铺出来，行号连续可读。
  - 顶部按钮、`Alt+↑/↓` 和 `F7 / Shift+F7` 可以跳到上一处 / 下一处差异，右侧改动导航条可直接跳转。
  - 支持并排 / 统一两种视图，可折叠未修改区块；仍然分批挂载，导航到更后面的差异时会自动扩展渲染窗口。
  - 长行可以用底部横向滚动条或 `Shift + 滚轮` 左右拖动。
  - 二进制文件、超过 2 MB、冲突 combined diff 或读不到完整文本时，自动回落到原来的差异块视图。
- 主进程新增两侧完整文本读取（工作区 / Git blob / SVN revision），统一做 LF 归一化后再交给渲染层对齐。

### 修复
- **diff 面板周期性闪烁**：后台 VCS 刷新失败时保留已有内容，不再把整块界面闪成错误页；diff 内容没有变化时复用旧对象，避免整棵 diff 树重复渲染。
- **上下文用量显示错误**：长轮次不再把整轮累计 token 当成当前上下文。之前 13 步的轮次会显示 `4.3M / 1M` 并误报「接近上限」；现在按最后一次请求的输入、缓存和输出计算。

## 安装
Windows 安装版支持自动更新；便携版需手动下载。从 1.2.22 及更早版本手动安装一次 1.2.23 后，后续更新即可正常在应用内下载。
