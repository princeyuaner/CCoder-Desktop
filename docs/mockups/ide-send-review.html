IDE → 聊天：代码 / 文件发送

选中一段代码或整个文件，放进同工作区的聊天输入框，作为消息的代码引用。下面是三个场景的真实界面效果。

1

选中代码发送

浮动条 + 确认层

交互

  • 选中代码后，选区底部出现 已选 N 行 · 复制 · 发送到聊天。
  • 确认层展示目标会话、文件名、L464–476、相对路径、行数和代码预览。
  • 面包屑右侧常驻 发送选区，不依赖浮动条。
  • 点「发送」只把引用放进输入框，不会直接发给模型。
2

整个文件发送

资源管理器 + 面包屑两个入口

入口

  • 资源管理器文件行悬停，右侧出现发送图标。
  • 当前文件在面包屑上常驻 发送文件。
  • 确认层引用范围变成 全文 · 218 行，不再带行号区间。
  • 和选区发送共用同一套目标会话与确认交互。
3

聊天框接收

输入框上方的代码引用卡

规则

  • 引用卡和图片附件同区，位于输入框上方。
  • 每条引用可单独移除，支持多个引用并存。
  • 来自 IDE 标签标明来源；代码文本随消息一起进入模型上下文。
  • 用户补完问题后正常发送，不改变现有发送流程。
