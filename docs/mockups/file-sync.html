设计说明

交互骨架：点击左侧活动栏的 ⇄ 同步 进入工作区；配置、状态、日志都在同一屏， 不用跳到聊天窗口的设置页。底部气泡只在「真的复制 / 删除 / 失败」时出现，点它打开日志浮层。

和 CCoder 版一致的

  • 单向镜像 + 内容对账：先看 (大小, mtime)，必要时才读内容；稳态下几乎零写入。
  • 安全删除：目标端那份自上次同步后被别处改过，就只提醒、不删；目标端自己生成的文件永远不动。
  • 三层过滤：同步范围 → 排除项 → 内置噪音规则，扫描 / 监听 / 删除共用同一份判定。
  • 静默期 + 巡检 + 退避：事件只当提示；巡检兜底；失败按 5→10→20→30→60 秒退避。
  • 占位锁：同一对目录只允许一个窗口同步，另一个窗口显示「被占用」并每分钟重试。

落到 Electron IDE 的改动

  • 同步与「源代码管理」平级，作为 第四个活动栏视图；配置不再藏进设置页。
  • CCoder 的「同步气泡」改成 底部 toast（贴左栏）（IDE 没有同步卡可贴气泡），3 秒自动收，点开是日志浮层。
  • 状态栏只在配置完成之后出现：运行中 / 同步出错 / 另一窗口。点击直接打开同步工作区。
  • 目标端仍是本地盘 / 映射网络盘；SSH 传输不在第一版，但 UI 与引擎按「可换后端」设计。
  • 每个 IDE 窗口一份配置（源默认当前工作区），关闭窗口即停，不跨窗口串目录。

想请你拍板的

  • 配置放在同步工作区（当前稿）还是聊天窗口的设置页？我倾向前者，少一次跳转。
  • 是否保留「立即同步」和暂停按钮？自动化之外给一个手动入口，适合刚改完想立刻确认。
  • 同步对是每个工作区一份（当前稿），还是全局可配多对？多对会明显增加面板与调度复杂度。
  • 失败时是否弹出系统通知（窗口在后台也能看见），还是只在 IDE 内提示？
