几点说明
  • 只有 16px。会话行前面的图标是 .session__cli 的 16×16 —— A / B / C 这三种「转 / 摆 / 跳」在这个尺寸下都只能靠位移感知，字形本身看不出在转。真正 16px 下还成立的只有 E（环）和 F（点）。
  • 「运行中」不等于「当前打开」。现在 .session.is-active 已经有底色了，指示器必须独立于它 —— 后台子代理还在跑时，你切去看别的会话，那一条也该继续转。
  • 可选叠加：运行中的那一行，把右侧的相对时间（.session__time）换成珊瑚色的「运行中」两个字，状态更明确；这个跟图标动效互相独立，可以只做其中一样。
  • 数据从哪来：现在侧栏拿不到运行状态 —— SessionManager 里的 live 表在主进程，sessionStatus 事件只广播给正在看的那条会话（useChat 按 sessionId 过滤）。要做这个效果，需要把「哪些 providerSessionId 在跑」一并推给侧栏。
