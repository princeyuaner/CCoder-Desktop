方案模型费用中文网络说明
硅基流动 推荐默认 FunAudioLLM/SenseVoiceSmall 免费 好 国内直连 OpenAI 兼容，注册后在控制台创建 API Key 即可。
Groq whisper-large-v3-turbo 免费额度 好 需海外网络 质量高、延迟低；额度按音频秒数计，以控制台为准。
系统听写 Win+H / macOS Fn×2 零配置 系统级 不需要 今天就能用的兜底，不经过应用；适合临时输入。

关于“免费”：免费额度、模型可用性和速率限制由服务商随时调整，接入时以各自控制台为准。 Cloudflare Workers AI 等也有每日免费额度，但接口不是 OpenAI 兼容，v1 不做适配。
建议：默认预置硅基流动，用户在设置里粘贴自己的免费 Key 即可；不想用云服务时，可以先用系统听写兜底。 本地 whisper.cpp / 离线模型不在 v1 范围，后续再评估。
