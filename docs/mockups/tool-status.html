状态规范（三案通用）

颜色只是辅助，每种状态都有独立图标 / 文案；「已拒绝」不再和失败共用红色。

状态标记颜色默认行为
成功 · ok 绿色对勾（A） / 对勾 + 完成（C） 文字 #8fd39a · 底 rgba(75,158,95,.16) 保持折叠；悬停才显示输出入口。工具多时靠左色条扫读。
失败 · error 红叉 + 「失败」
折叠态直接给错误摘要		 边框 rgba(229,83,75,.36) · 底 rgba(229,83,75,.055) 自动露出前 2 行错误；有退出码时一并显示（Codex exitCode / DSH [exit code: N]），完整输出按需展开。
已拒绝 · denied ⊘ + 「已拒绝」 琥珀 #d9b45a；不用红色 视为「未执行」而非「执行失败」，不触发错误计数与错误摘要。
运行中 · running 旋转圈 + 「运行中」 珊瑚 #d97757 耗时持续跳动；完成后原位替换为成功 / 失败，不新增卡片。
01不只靠颜色。四态各有图标 + 文案，色盲与灰度截图下仍可分辨。
02失败不用点开。折叠态就显示退出码 + 首行错误，最多两行，超出省略。
03成功安静但不隐形。对勾常驻、不填底色；不抢助手正文的注意力。
04精简模式保留状态。只隐藏目录与工具名，对勾 / 失败标签始终显示。
05失败卡不自动展开全部输出。先给摘要，完整内容一次点击，避免刷屏。
06拒绝不是失败。琥珀色、无错误摘要，避免把用户自己的选择标成系统故障。
