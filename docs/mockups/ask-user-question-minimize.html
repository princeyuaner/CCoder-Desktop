AskUserQuestion · 最小化

交互：用右上角的 展开 / 收起 切换状态，也可以直接点收起后的 条形 / 胶囊 / 待回答条 / 徽标 展开。

四案共用的行为约定

  • 只作用于当前这组提问：已选项、当前题号、「其他」里输入的文字全部保留；下次展开原样恢复。
  • 新的一组提问到达时自动展开，不会因为上一组被收起而漏掉新的问题。
  • 收起期间输入框仍然锁定：模型在等答案，不能把新消息塞进正在等待的一轮。
  • 收起态不提供「跳过」，避免误触；要跳过请展开后按 Esc 或点「跳过」。
  • 不抢键：Esc 仍然只做「跳过」，收起/展开用显式按钮和点击，不新增全局快捷键。
  • 焦点：收起后焦点回到转写区；展开后焦点回到抽屉，↑↓ / 数字键立即可用；aria-expanded 跟随状态。
  • 动效：160ms ease-out；prefers-reduced-motion 下直接切换。
  • 切换会话：再回到这个会话时默认展开（收起状态暂不持久化，可后续加）。
