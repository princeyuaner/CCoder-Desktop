行为说明（供审批）

版本卡下面新增一块「更新」，只在检测到有新版本时变成强调态；其余时候保持安静，不弹窗、不打扰会话。

检测方式

  • 当前版本：跑 claude --version / codex --version / dsh --version，从输出里抓版本号（沿用现有 version 字段，不新增探测进程）。
  • 最新版本：读 npm registry 的 https://registry.npmjs.org/<pkg>/latest，只取 version 字段；结果缓存 6 小时，离线时用缓存并标「离线」。
  • 安装方式：比对 CLI 可执行文件路径是否落在 npm root -g 下 —— 是才给「更新」按钮，不是就降级成复制命令（状态 5）。

时机

  • 打开对应 CLI 的设置页时检查一次（先渲染上次结果，不闪空白）。
  • 之后每 6 小时后台检查一次，只在主进程做，不占用会话进程。
  • 检查失败不报红错，只在卡片里降级提示（状态 6）。

更新这个动作

  • 主按钮 → 有运行中会话时先确认（状态 7）→ 后台跑 npm install -g <pkg>@<latest> → 进度条 + 可取消。
  • 成功后自动重跑 --version 刷新卡片，并说明「新会话才生效」。
  • 失败就停在状态 4，给出原始 npm 错误、复制命令、以及「以管理员身份重试」（Windows 全局目录常见）。
  • 绝不做静默自动升级：CLI 是用户自己的工作环境，升级只由用户点击触发。
